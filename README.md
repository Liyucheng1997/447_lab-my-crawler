# 我的爬虫

本地运行的网页资源抓取工具：输入网址，找出页面里的图片、视频、音频、文件、链接、正文和表格，勾选后下载到本机。仅供个人学习使用。

## 启动

双击 `启动.bat`，或者：

```bash
pip install -r requirements.txt
python app.py
```

浏览器会自动打开 http://127.0.0.1:8447 。下载的文件在 `downloads/网站域名/类型/` 下。

## 功能

- **抓什么**：图片 / 视频 / 音频 / 文件（pdf、zip、office 文档等）/ 链接 / 正文 / 表格，可多选
- **范围**：只抓当前页，或顺着站内链接再跟进 1～2 层（可设最多页数和每页间隔）
- **自定义选择器**：填 CSS 选择器（如 `.quote .text`），把匹配到的元素文字和链接单独列出来
- **浏览器渲染**：内容靠 JS 加载的网站，勾上后用无头浏览器打开再解析（需要 `playwright install chromium`，或本机有 Edge / Chrome）
- **下载**：普通文件直接下载；m3u8 流媒体和嵌入的视频播放器交给 yt-dlp 合并成一个文件
- **导出**：当前页签的结果导出 JSON / CSV，表格单独导出 CSV，正文存为 TXT

## 文件

| 文件 | 作用 |
| --- | --- |
| `app.py` | 网页服务、下载、接口 |
| `crawler.py` | 抓取和解析 |
| `static/` | 界面（`tokens.css` 是设计变量） |

## 注意

- 默认遵守网站的 robots.txt，每页之间至少间隔 0.2 秒。
- 需要登录、有验证码或明确拒绝自动访问的网站（比如维基百科会返回 403）抓不到，工具不做绕过。
- 抓到的内容版权归原网站，别拿去公开传播或商用。
